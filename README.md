# 🌐 Mycelium | Inteligencia Geoespacial para la Movilidad Urbana

**Mycelium** es un Sistema de Soporte a la Decisión (DSS) diseñado para optimizar la expansión de redes de transporte masivo en metrópolis mexicanas. Desarrollado como proyecto final de grado en la **Metropolitan University of Monterrey (UMM)**, el sistema transforma datos demográficos y geográficos en estrategias de conectividad urbana eficiente.

## 🚀 Descripción del Proyecto

El sistema utiliza algoritmos avanzados para identificar agrupamientos demográficos críticos (clústers) y optimizar rutas sobre grafos viales. Mycelium es agnóstico a la infraestructura previa, permitiendo dimensionar redes en cualquier ciudad del país mediante la integración de marcos geoestadísticos oficiales.

## 🛠️ Stack Tecnológico

Como estudiante de **Tecnologías de la Información**, he seleccionado herramientas que garantizan escalabilidad y precisión técnica:

- **Frontend**: [Astro](https://astro.build/) para una entrega de alto rendimiento y diseño responsivo.
- **Procesamiento de Datos**: Python y QGIS para el análisis geoespacial y manejo de archivos `.gpkg`.
- **Control de Versiones**: Git para la gestión del flujo de trabajo.
- **Despliegue**: Vercel para una integración continua (CI/CD).

## 📊 Fuentes de Datos Oficiales

El rigor estadístico del proyecto se fundamenta en la ingesta de insumos de instituciones nacionales:

- **INEGI**: Censo de Población y Vivienda 2020 y DENUE 2025.
- **CONEVAL**: Variables de rezago social para priorizar zonas desconectadas.
- **OpenStreetMap**: Datos de infraestructura vial y capacidad de carriles para el filtrado de rutas.

## ⚖️ Marco Jurídico y Sostenibilidad

El diseño de Mycelium no solo es técnico, sino que se alinea con normativas vigentes y objetivos globales:

- **LGMSV**: Aplicación del Artículo 35 para priorizar la jerarquía de movilidad.
- **ODS 11.2**: Contribución al acceso universal a transporte seguro, sostenible y equitativo.

## 📁 Estructura del Repositorio

- `/src`: Código fuente del componente de visualización (Astro).
- `/public`: Recursos estáticos, incluyendo el video demostrativo de la interfaz.
- `/data`: Estructuras GeoPackage y archivos `.xlsx` utilizados en el proyecto.
